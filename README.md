# Predictive Analytics Using Historical Data

## Project Overview
This project predicts future sales trends using historical sales data and machine learning techniques.

## Features
- Data preprocessing
- Linear regression model
- Model evaluation
- Future sales forecasting
- Data visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Output
The model predicts future sales and visualizes trends using graphs.

## How to Run
1. Install required libraries
2. Run:
   python predictive_analysis.py
